# Kagurabachi Craft Wiki

Public player documentation for Kagurabachi Craft 5.0.0 on NeoForge 1.21.1.

## Local development

Requires Node.js 20 or newer.

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```

The site source is in `src`, static files are in `public`, and gameplay screenshots are in `src/assets/screenshots`.
